{% trans "What is a DaisyUI menu?" %}

{% blocktrans trimmed %} A menu is a reusable set of navigation components that can be dropped into any page. Build the items here once, then render the menu with the daisyui_menu template tag or the "Menu" block. {% endblocktrans %}

  • {% blocktrans trimmed %} Layout — whether the menu renders as a top navbar, footer, sidebar drawer, or a standalone horizontal/vertical list. {% endblocktrans %}
  • {% blocktrans trimmed %} Brand — an optional logo and site name shown at the start of a navbar. {% endblocktrans %}
  • {% blocktrans trimmed %} Search — optionally show a search box pointing at your site's search URL. {% endblocktrans %}
  • {% blocktrans trimmed %} Theme toggle — optionally show a light/dark switch that applies another DaisyUI theme. {% endblocktrans %}
  • {% blocktrans trimmed %} Menu items — add Link, Button, Search box, Inline card and Newsletter components, or an Accordion that nests sections, links and featured cards. Section and Text blocks are handy for footer columns and legal text. {% endblocktrans %}

{% blocktrans trimmed %} Use the Settings tab to control the container colours and sizing. {% endblocktrans %}
